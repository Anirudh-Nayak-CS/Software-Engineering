# Serve Qwen from Kaggle

Run the model in a Kaggle notebook with GPU acceleration enabled. The local app calls this server through an ngrok HTTPS endpoint.

The ready-to-run notebook is [qwen_server_kaggle.ipynb](qwen_server_kaggle.ipynb). Upload that one notebook to Kaggle and run its cells from top to bottom. It installs the Kaggle-side packages, writes `qwen_server.py`, starts Qwen, waits for readiness, and opens the ngrok tunnel. It streams keepalive events during generation to prevent ngrok's idle timeout. You do not need to make a separate notebook or upload a separate server file.

## Kaggle setup

1. Create Kaggle secrets named `NGROK_AUTHTOKEN` and `MODEL_API_KEY`. Use a long random value for `MODEL_API_KEY`.
2. Start a Kaggle notebook with a GPU accelerator enabled.
3. Upload `qwen_server.py` from this folder into `/kaggle/working`.
4. Install the inference server dependencies in a notebook cell:

```python
%pip install -q "transformers>=4.51.0" accelerate fastapi uvicorn pyngrok
```

5. Load the Kaggle secrets and start the model server:

```python
import os
import subprocess
import sys
from kaggle_secrets import UserSecretsClient

secrets = UserSecretsClient()
os.environ["MODEL_API_KEY"] = secrets.get_secret("MODEL_API_KEY")
os.environ["NGROK_AUTHTOKEN"] = secrets.get_secret("NGROK_AUTHTOKEN")
server = subprocess.Popen([
    sys.executable, "-m", "uvicorn", "qwen_server:app",
    "--host", "0.0.0.0", "--port", "8000",
], cwd="/kaggle/working", env=os.environ.copy())
```

6. Start an ngrok tunnel and copy the printed endpoint:

```python
from pyngrok import ngrok

ngrok.set_auth_token(os.environ["NGROK_AUTHTOKEN"])
tunnel = ngrok.connect(8000, "http")
print(tunnel.public_url)
```

Keep the Kaggle session and tunnel running while using the app. The model download and inference stay in Kaggle. The inference route requires the `MODEL_API_KEY` bearer token.

## Connect the local app

In `backend/.env`, set `MODEL_API_BASE_URL` to the printed endpoint with `/v1` appended, and set `MODEL_API_KEY` to the same secret value used in Kaggle. These values stay in the backend and are not sent to the browser. Restart the backend after changing them.

The local backend continues to do BM25 retrieval and the LangGraph orchestration. Both generation steps are sent to the Kaggle Qwen endpoint. The PDF is still generated by the local backend.
